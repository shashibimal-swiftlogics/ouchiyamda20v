# Registers (draft v0.1, 2026-11-20)
Each register is a table kept current by whoever changes the thing it records. Master copies of decisions, claims and assets are in the All-in-One Master (Claude Docs).

| Register | Holds | Status |
|---|---|---|
| Decision register | Open and closed decisions (V-, V3-Q, CIN-Q, C-Q, H-Q) with date and decider | in Master section 15 and v3.1; to copy here |
| Claims and evidence register | Each claim, source, date, status | claims on hold listed in AGENTS.md |
| Asset register | Each asset, owner, rights, approval | in Master section 12; to copy here |
| Route and page inventory | Every route, blueprint, access, state | docs/blueprints/README.md |
| Task board | Tasks, owner, branch, reviewer, status | docs/TASKS.md |
| Test report | Build, test and accessibility results per PR | to create |
| Risk register | Risks and responses | in Master section 14; to copy here |
| Approval log | Who approved what, when | to create |
